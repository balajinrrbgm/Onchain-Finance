# Smart Contract Workspace

This folder is prepared for deploying Hedera Smart Contract Service (HSCS) artifacts when extending AfriAsset with automated yield distribution, collateral vaults, or compliance guards.

Suggested next steps:
- Use Hardhat + `@hashgraph/hardhat-hethers` to deploy EVM-compatible Hedera contracts.
- Implement income sharing contracts to stream RWA yields back to token holders.
- Add guard contracts for collateral liquidation and DAO-based governance.
